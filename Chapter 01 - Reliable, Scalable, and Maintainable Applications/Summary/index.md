# Summary

## Key Takeaways

### The Three Concerns
1. **Reliability** - The system continues to work correctly even when things go wrong
2. **Scalability** - The system can handle increased load gracefully
3. **Maintainability** - Different people can work on the system productively

### Important Concepts
- Data systems include databases, caches, search indexes, message queues, and batch processing
- Faults are different from failures
- Load parameters are system-specific
- Tail latency matters in large-scale systems
- Good systems are operable, simple, and evolvable
