# Reliability

## Key Points

### What is Reliability?
- The system continues to work correctly even when things go wrong
- **Fault**: A component deviating from its spec
- **Failure**: The system as a whole stops providing the required service

### Types of Faults

#### Hardware Faults
- Hard disk crashes
- RAM errors
- Network outages
- Power failures
- Redundancy through RAID, multiple machines

#### Software Errors
- Bugs in the code
- Race conditions
- Memory leaks
- Cascading failures
- Software is harder to make redundant

#### Human Errors
- Configuration mistakes
- Accidental data deletion
- Bugs in production code
- Misunderstanding the system

### How Important Is Reliability?
- Different systems have different requirements
- Medical systems vs. social media
- The cost of downtime
