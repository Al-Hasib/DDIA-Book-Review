# Maintainability

## Video Timestamp

## Key Points

### What is Maintainability?
- Making life easy for the people who need to work on the system
- A good system should be well-designed and documented

### Three Pillars of Maintainability

#### 1. Operability: Making Life Easy for Operations
- Good visibility into system state
- Good automation
- Good documentation
- Easy to understand and modify

#### 2. Simplicity: Managing Complexity
- Reduce complexity as much as possible
- Good abstractions
- Clean code
- Avoid accidental complexity

#### 3. Evolvability: Making Change Easy
- The system should be easy to modify
- Good test coverage
- Loose coupling
- High cohesion
