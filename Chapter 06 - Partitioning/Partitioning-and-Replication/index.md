# Partitioning and Replication

## Key Points

### Why Partition?
- Single machine can't store all data
- Single machine can't handle all queries
- Partitioning enables horizontal scaling

### Partitioning vs Replication
- **Partitioning**: Split data across nodes
- **Replication**: Copy data across nodes
- Usually combined: partition and replicate each partition

### Partitioning Goals
- Balance data evenly across nodes
- Minimize cross-partition queries
- Handle hot spots

1. When would you partition but not replicate?
2. How do partitioning and replication interact?
3. What are the challenges of combining them?
