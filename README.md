# Designing Data-Intensive Applications (DDIA) - YouTube Playlist

> A comprehensive video series teaching the big ideas behind reliable, scalable, and maintainable systems.

## About This Playlist

This YouTube playlist covers Martin Kleppmann's "Designing Data-Intensive Applications" - one of the most important books for understanding modern data systems. Each chapter is broken down into digestible video segments with detailed notes and discussion questions.

## Why This Book Matters

Understanding data systems is crucial for building:
- **Reliable** systems that work correctly even when things go wrong
- **Scalable** systems that handle increased load gracefully
- **Maintainable** systems that different people can work on productively

## Key Concepts Covered

### Reliability
- Hardware faults and redundancy
- Software errors and testing
- Human errors and processes

### Scalability
- Load parameters and performance metrics
- Vertical vs horizontal scaling
- Architectural patterns

### Maintainability
- Operability and monitoring
- Simplicity and abstractions
- Evolvability and change

### Data Models
- Relational vs document models
- Query languages (SQL, MapReduce, SPARQL)
- Graph databases

### Storage & Retrieval
- B-Trees vs LSM-Trees
- OLTP vs OLAP
- Column-oriented storage

### Encoding
- JSON, XML, Protocol Buffers, Avro
- Schema evolution
- Dataflow patterns

### Replication
- Leader-based, multi-leader, leaderless
- Consistency and availability tradeoffs
- Conflict resolution

### Partitioning
- Key range vs hash partitioning
- Secondary indexes
- Rebalancing strategies

### Transactions
- ACID properties
- Isolation levels
- Serializability

### Distributed Systems
- Faults and partial failures
- Unreliable networks and clocks
- Consistency and consensus

### Batch & Stream Processing
- MapReduce and beyond
- Event streaming
- Real-time analytics
