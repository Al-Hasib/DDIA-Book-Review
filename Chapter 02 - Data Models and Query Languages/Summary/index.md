# Summary

## Key Takeaways

### Data Models Matter
- Different data models are suited to different use cases
- The model shapes how we think about problems

### Relational vs Document
- Relational databases are still the default choice
- Document databases excel at hierarchical data
- Both have tradeoffs in schema flexibility, performance, and query power

### Query Languages
- Declarative queries are generally better than imperative
- MapReduce is powerful for batch processing
- Different languages for different data models

### Graph Models
- Essential for highly connected data
- Property graphs and triple-stores are the main approaches
- Graph queries are more natural for relationship-heavy queries
