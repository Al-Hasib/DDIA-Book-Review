## Key Takeaways

### Encoding Formats
- Text formats (JSON, XML) are human-readable but verbose
- Binary formats (Thrift, Protocol Buffers, Avro) are compact and efficient
- Schema evolution is essential for system longevity

### Modes of Dataflow
- Through databases: Simple but synchronous
- Through services (REST/RPC): Network-based, synchronous
- Through message queues: Asynchronous, decoupled

### Schema Evolution
- Forward compatibility: New code reads old data
- Backward compatibility: Old code reads new data
- Avro excels at schema evolution
